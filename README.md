# 🎮 BackTogether (백투게더)

**BackTogether(백투게더)**는 협동과 타이밍이 중요한 2D 온라인 멀티플레이어 협동(Co-op) 플랫포머 게임입니다. 플레이어들은 다양한 기믹과 퍼즐, 함정을 돌파하며 서로 힘을 합쳐 목표 지점까지 도달하고 '다시 함께' 모여야 합니다.

## 🌟 주요 특징 (Features)

* **온라인 멀티플레이 지원**: Mirror 네트워킹과 Steam/Epic Online Services(EOS) 연동을 통한 로비 생성, 빠른 참가, 친구 초대 기능.
* **협동 중심의 플랫포머 기믹**:
  * **플랫폼 및 지형**: 시소(Seesaw), 거울(Mirror), 이동 통나무, 토글 발판 등
  * **함정 및 장치**: 타이머 스파이크 게이트, 수리검 함정, 여러 명이 함께 밟아야 하는 다중 버튼
  * **특수 환경(Zone)**: 눈보라(Blizzard), 중력 역전(Gravity), 동기화 점프(SyncJump), 강풍(Wind), 분리 구역(Separate)
  * **플레이어 상호작용**: 두 명 혹은 네 명이 합체하는 기믹(Combine), 로프 액션, 시야 제한(Darkness/Flashlight) 및 메아리 빛 기믹 등
* **다양한 챕터 구성**: 총 4개의 챕터로 구성된 다채로운 레벨 디자인과 점진적으로 어려워지는 퍼즐.
* **조작 및 편의성**: 게임패드 완벽 지원(New Input System), 체크포인트 및 리스폰 시스템.

## 👥 팀원 및 역할 (Team 'MoriSoft')

* **Bae (배)**
  * **네트워크 & 메인**: Mirror 및 로비 시스템, 방 생성/검색, Steam/EOS 플랫폼 연동
  * **기믹 (Gimmicks)**: 스위치, 발판, 트랩, 특수 환경(Zone), 플레이어 상호작용(합체/로프 등) 기믹 프로그래밍
* **Choi (최)**
  * **UI / UX**: 게임 내 로비 창, 챕터 선택 화면, 일시정지 옵션, 각종 메뉴 UI 구현 및 리소스 적용
* **Seo (서)**
  * **플레이어 모듈 (Player Module)**: 캐릭터 애니메이션, 물리 연산, 키보드 및 게임패드 입력, 이동 및 넉백 시스템
* **Sin (신)**
  * **레벨 디자인 및 리소스**: 배경 디자인, 타일맵(Tile/RuleTile), 각종 씬 구성 및 퍼즐 레벨 디자인
  * **사운드**: 배경음악(BGM) 및 효과음(SFX) 관리 및 적용

## 🛠 사용 기술 및 도구 (Tech Stack)

* **Game Engine**: Unity
* **Networking**: Mirror, Steamworks.NET, Epic Online Services
* **Input**: Unity New Input System (Keyboard + Gamepad)
* **Version Control**: Git / GitHub
